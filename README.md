## Возможности

- **Свежая лента 2026 года**: Автоматический обход геоблокировок РФ на уровне приложения через встроенное SOCKS5-реле без изменений системного прокси или VPN.
- **Прямое воспроизведение видео на полной скорости**: Все видео- и медиа-потоки (CDN Akamai / ByteDance) передаются напрямую на гигабитной скорости вашего провайдера.
- **Дата публикации у каждого видео**: Точная дата загрузки (`· 27.10.2026`) аккуратно выводится возле ника автора в ленте и видео.
- **Вкладка «Репосты»**: Разблокированная и полностью функциональная вкладка репостов в профилях пользователей.
- **Скачивание видео в один клик**: Кнопка «Скачать видео» автоматически перехватывает оригинальный CDN-поток и сохраняет MP4 в вашу папку «Загрузки».
- **100% нативный стиль TikTok Dark Mode**: Чистый минималистичный интерфейс, шрифты TikTok Sans, аккуратная плавающая шестеренка настроек в правом нижнем углу и горячая клавиша `Правый Alt` (или `0`).
- **Фильтрация контента**: Возможность в один клик скрыть рекламу, стримы (LIVE) или фото-карусели.

## Быстрый старт

### Требования
- **Windows 10 / 11**
- **Python 3.10+** ([python.org](https://www.python.org/))
- **Google Chrome** или **Microsoft Edge**

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/YOUR_USERNAME/tiktok-fix.git
cd tiktok-fix
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите клиент:
Дважды кликните по `TikTok_Fix.bat` или запустите через консоль:
```bash
pythonw tiktok_fix.py
```

## Горячие клавиши и управление

- **Правый Alt** или **0** — открыть / закрыть меню настроек TikTok Fix.
- **Кнопка-шестеренка** в правом нижнем углу экрана — быстрое меню мода:
  - Выбор региона подключения (Франция, Германия, Нидерланды, США, Прямой).
  - Кнопка «Скачать видео» (сохраняет текущее открытое видео).
  - Переключатели блокировки рекламы, трансляций и фото.
  - Кнопка «Переподключиться» (ротация рабочего узла).

## Безопасность

Профиль браузера (`tiktok_fix_profile/`) хранится локально на вашем компьютере и добавлен в `.gitignore`. Ваши пароли, сессии и авторизация никогда не передаются на сторонние серверы и не попадут в репозиторий.
