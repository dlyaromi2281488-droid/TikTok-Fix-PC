# TikTok Fix

Десктопный клиент TikTok для Windows. Позволяет смотреть новые рекомендации и видео в РФ без включения системного VPN.

## Установка

1. Скачайте репозиторий (или архив).
2. Запустите файл `Установка.bat` — он автоматически проверит Python, установит необходимые библиотеки и создаст красивый ярлык «TikTok Fix» на Рабочем столе.
3. Запускайте приложение через ярлык на Рабочем столе или файл `TikTok_Fix.bat`.

## Возможности

- **Свежие рекомендации 2026** через встроенный локальный SOCKS5-релей с автовыбором быстрых прокси.
- **Прямое воспроизведение видео**: потоки с CDN идут напрямую на полной скорости вашего интернета (без задержек и буферизации).
- **Мгновенное скачивание**:
  - Кнопка «Видео (MP4)» скачивает оригинальный чистый видеофайл напрямую в папку `Загрузки`.
  - Кнопка «Звук (MP3)» скачивает музыкальную дорожку в папку `Загрузки`.
- **Даты публикации**: точная дата (ДД.ММ.ГГГГ) отображается прямо возле ника автора под каждым видео.
- **Вкладка «Репосты»**: полноценный просмотр репостов в профилях пользователей.
- **Интерактивный PiP («Картинка в картинке»)**: перелистывание ленты колесиком мыши (вверх/вниз) или стрелками прямо над мини-окном, перемотка на 3 сек, а также автоматический переход к следующему видео по окончании текущего.
- **Плавная перемотка**: нативные 3 секунды без конфликтов и лишних уведомлений.
- **Регулировка громкости колесиком мыши** над областью плеера.
- **Выбор региона**: Германия (DE), Нидерланды (NL), США (US), Франция (FR), Великобритания (GB), Польша (PL), Швеция (SE), Япония (JP), Сингапур (SG), Прямое подключение (DIRECT).
- **Чистый нативный интерфейс**: темная тема TikTok, никаких смайликов и баннеров предупреждений браузера.

## Управление и горячие клавиши

- **Правый Alt** или **0** — открыть меню мода.
- **← / →** — перемотка назад/вперед на 3 секунды.
- **[ / ]** — уменьшение / увеличение скорости воспроизведения (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x).
- **P** — режим «Картинка в картинке» (PiP).
- **Колесико мыши над видео** — плавная регулировка громкости.
- **Кнопка с шестеренкой в правом нижнем углу**:
  - Выбор региона подключения.
  - Скачивание видео (MP4).
  - Скачивание звука (MP3).
  - Фильтры рекламы, стримов и фото.

## Запуск из исходного кода

### Требования
- Windows 10 / 11
- Python 3.10+
- Google Chrome или Microsoft Edge

### Установка зависимостей и запуск

```bash
git clone https://github.com/dlyaromi2281488-droid/TikTok-Fix-PC.git
cd TikTok-Fix-PC
pip install -r requirements.txt
pythonw tiktok_fix.py
```

Также можно запускать через `TikTok_Fix.bat` или ярлык на Рабочем столе.

## Структура файлов

- `tiktok_fix.py` — ядро десктопного приложения, локальный API и инжекция скриптов
- `tiktok_relay.py` — локальный высокоскоростной SOCKS5 релей с умной маршрутизацией CDN
- `injected_script.js` — модуль интерфейса (рекомендации, даты, репосты, плеер, горячие клавиши, скачивание)
- `extension/` — вспомогательное расширение для браузера
- `requirements.txt` — список необходимых библиотек python
- `create_shortcut.vbs` — скрипт генерации ярлыка на Рабочем столе
- `run_silent.vbs` — запуск приложения без всплывающего черного окна консоли
- `TikTok_Fix.bat` — лаунчер
- `Установка.bat` — установщик для пользователя

## Приватность

Данные авторизации и профиль (`tiktok_fix_profile/`) хранятся исключительно локально на вашем компьютере и исключены из репозитория через `.gitignore`.
