# TikTok Fix

Десктопный клиент TikTok для Windows. Позволяет смотреть новые рекомендации и видео в РФ без включения системного VPN.

## Установка

1. Скачайте `TikTok_Fix_Setup.exe` со страницы [Releases](https://github.com/dlyaromi2281488-droid/TikTok-Fix-PC/releases/latest).
2. Запустите файл и нажмите «Установить».
3. После установки на рабочем столе появится ярлык для запуска.

Если не хотите устанавливать в систему, скачайте `TikTok_Fix_Portable.zip`, распакуйте в любую папку и запускайте `TikTok Fix.exe`.

## Возможности

- Свежие рекомендации (лента 2026) через встроенный прокси-релей.
- Прямое воспроизведение видео с CDN без потери скорости.
- Дата публикации возле ника автора у каждого видео.
- Вкладка репостов в профилях.
- Скачивание видео в mp4 в один клик.
- Темная тема оформления.
- Скрытие рекламы, прямых эфиров и фото-постов.

## Управление

- Правый Alt или 0 — открыть меню настроек.
- Кнопка с шестеренкой в правом нижнем углу:
  - Выбор региона подключения (Франция, Германия, Нидерланды, США, Прямой).
  - Скачивание открытого видео.
  - Фильтры рекламы, стримов и фото.
  - Смена рабочего прокси-сервера.

## Запуск из исходного кода

### Требования
- Windows 10 / 11
- Python 3.10+
- Google Chrome или Microsoft Edge

### Установка зависимостей и запуск

```bash
git clone https://github.com/dlyaromi2281488-droid/TikTok-Fix-PC.git
cd TikTok-Fix-PC
pip install -r requirements.txt
pythonw tiktok_fix.py
```

Также можно запускать через `TikTok_Fix.bat`.

## Структура файлов

- `tiktok_fix.py` — запуск браузера, локальный API и инжекция скриптов
- `tiktok_relay.py` — локальный SOCKS5 релей с пулом прокси
- `injected_script.js` — скрипт интерфейса (даты, репосты, плеер)
- `extension/` — вспомогательное расширение для браузера
- `requirements.txt` — список библиотек python
- `TikTok_Fix.bat` — скрипт запуска без окна консоли

## Приватность

Данные авторизации и сессия (`tiktok_fix_profile/`) хранятся только локально на вашем компьютере и исключены из репозитория через `.gitignore`.
