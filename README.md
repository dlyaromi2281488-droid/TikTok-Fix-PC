# TikTok Fix

Десктопный клиент TikTok для Windows. Позволяет смотреть новые рекомендации и видео в РФ без включения системного VPN.

## Установка

1. Скачайте `TikTok_Fix_Setup.exe` или `TikTok_Fix_Portable.zip` со страницы [Releases](https://github.com/dlyaromi2281488-droid/TikTok-Fix-PC/releases/latest).
2. Запустите файл установки или распакуйте архив и запустите `TikTok Fix.exe`.
3. Либо скачайте репозиторий и запустите `Установка.bat` — он сам проверит окружение и создаст ярлык на рабочем столе.

## Возможности

- Свежие рекомендации через встроенный SOCKS5-релей.
- Прямое воспроизведение видео с CDN без потери скорости.
- Дата публикации возле ника автора у каждого видео.
- Вкладка репостов в профилях.
- Скачивание видео в MP4 и аудиодорожек в MP3 в один клик.
- Запоминание уровня громкости и регулировка колесиком мыши над плеером.
- Режим «Картинка в картинке» (PiP) для фонового просмотра.
- Быстрое копирование описания ролика и перевод текста.
- Встроенный перевод иностранных комментариев прямо в интерфейсе.
- Темная тема оформления и скрытие рекламы/стримов.

## Управление и горячие клавиши

- **Правый Alt** или **0** — открыть меню настроек.
- **← / →** — перемотка видео назад/вперед на 5 секунд.
- **[ / ]** — уменьшение / увеличение скорости воспроизведения (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x).
- **P** — включить / выключить режим «Картинка в картинке» (PiP).
- **Колесико мыши над видео** — плавная регулировка громкости.
- **Кнопка с шестеренкой в правом нижнем углу**:
  - Выбор региона подключения (Франция, Германия, Нидерланды, США, Прямой).
  - Скачивание открытого видео (MP4).
  - Скачивание звука (MP3).
  - Фильтры рекламы, стримов и фото.
  - Смена рабочего прокси-сервера.

## Запуск из исходного кода

### Требования
- Windows 10 / 11
- Python 3.10+
- Google Chrome или Microsoft Edge

### Установка зависимостей и запуск

```bash
git clone https://github.com/dlyaromi2281488-droid/TikTok-Fix-PC.git
cd TikTok-Fix-PC
pip install -r requirements.txt
pythonw tiktok_fix.py
```

Также можно запускать через `TikTok_Fix.bat`.

## Структура файлов

- `tiktok_fix.py` — запуск браузера, локальный API и инжекция скриптов
- `tiktok_relay.py` — локальный SOCKS5 релей с пулом прокси
- `injected_script.js` — скрипт интерфейса (даты, репосты, плеер, горячие клавиши)
- `extension/` — вспомогательное расширение для браузера
- `requirements.txt` — список библиотек python
- `TikTok_Fix.bat` — скрипт запуска без окна консоли
- `Установка.bat` — скрипт авто-установки и создания ярлыка

## Приватность

Данные авторизации и сессия (`tiktok_fix_profile/`) хранятся только локально на вашем компьютере и исключены из репозитория через `.gitignore`.
